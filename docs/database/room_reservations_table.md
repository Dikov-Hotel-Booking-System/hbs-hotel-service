# 📋 room_reservations

> Удержания номеров на период `[start_date, end_date)`. Записи с `released = false` учитываются при проверке пересечений. После освобождения запись сохраняется, чтобы запоздалое подтверждение по тому же `booking_id` не заняло номер снова.

## 🧾 Поля таблицы

| Поле | Тип | Обязательность поля | Значение по умолчанию | Описание |
|------|-----|------------------:|----------------------|----------|
| `booking_id` | `bigint` | ✅ | — | Идентификатор брони в Booking Service |
| `room_id` | `bigint` | ✅ | — | Номер, к которому относится удержание |
| `start_date` | `date` | ✅ | — | Дата заезда |
| `end_date` | `date` | ✅ | — | Дата выезда |
| `released` | `boolean` | ✅ | `false` | Признак освобождения номера |

---

## 🔒 Ограничения таблицы

| Ограничение | Поле / поля | Описание |
|-------------|-------------|----------|
| `pk_room_reservations` | `booking_id` | Одна запись на бронь |
| `fk_room_reservations_rooms` | `room_id` | Ссылка на `rooms.id` |
| `chk_room_reservations_dates` | `start_date`, `end_date` | Дата выезда строго позже даты заезда |
