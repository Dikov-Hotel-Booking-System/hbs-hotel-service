# 📋 rooms

> Номера отелей, их операционная доступность и счётчики бронирований.

## 🧾 Поля таблицы

| Поле | Тип | Обязательность поля | Значение по умолчанию | Описание |
|------|-----|------------------:|----------------------|----------|
| `id` | `bigint` | ✅ | `generated always as identity` | Идентификатор номера |
| `hotel_id` | `bigint` | ✅ | — | Отель, которому принадлежит номер |
| `number` | `varchar(50)` | ✅ | — | Обозначение номера в отеле |
| `available` | `boolean` | ✅ | `true` | Номер доступен для бронирования. Занятость на даты определяется по `room_reservations` |
| `times_booked` | `integer` | ✅ | `0` | Счётчик бронирований для подбора номеров |

---

## 🔒 Ограничения таблицы

| Ограничение | Поле / поля | Описание |
|-------------|-------------|----------|
| `pk_rooms` | `id` | Первичный ключ |
| `fk_rooms_hotels` | `hotel_id` | Ссылка на `hotels.id` |
| `uq_rooms_hotel_number` | `hotel_id`, `number` | Обозначение номера уникально в пределах отеля |
| `chk_rooms_times_booked` | `times_booked` | Счётчик неотрицательный |
